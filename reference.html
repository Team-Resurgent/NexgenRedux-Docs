Script reference

Everything that scripts can call, written by the engine itself. Types, namespaces and constants begin with a capital; functions and properties don't. A tag like Assets:: is a namespace: its calls are written Assets::texture(...).

Screen type

One place in the app. A screen's main.as has a class that implements this; it may have any of these methods.

void onEnter()Called once, when it opens and everything it asked for has loaded.
void update(float dt)Called 60 times a second. dt is in seconds.
void draw(Canvas@ canvas)Called to draw each frame.
void onSuspend()Called when another screen opens on top.
void onResume()Called when that one closes again.
void onExit()Called once, before it closes.
